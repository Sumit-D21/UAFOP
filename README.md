Decompress the folder 
To run it open terminal in this folder and run the following commands


- npm install

- npm start



Then open http://localhost:3001. To test the two-person flow, register as a parent, go to the Family tab to add a child (copy their invite code), then open the app in a second browser/device, choose "I have a code," and paste it. Chat between them is live. (npm test re-runs the end-to-end check I used.)
